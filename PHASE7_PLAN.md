## Gemini Code Generation Rules

**Include this section verbatim in the prompt when generating Phase 7 code with Gemini.
These rules address recurring failure modes found during Phase 5 and Phase 6 reviews.**

### Rule 1 — `enabled` guard on every conditional query
Any `useQuery` that should only fire for certain roles, states, or conditions MUST pass
an explicit `enabled: <boolean expression>` parameter. **Never** rely on error-handling
(`onError`, status checks) to suppress requests that should not be made. The API returns
hard errors (402, 403) for unauthorized callers — these errors must never fire in the first
place.

```typescript
// WRONG — fires for every user, customers get 402
const { data } = useQuery({ queryKey: ["analytics"], queryFn: () => apiClient.analytics.getMe() });

// CORRECT
const { data } = useQuery({
  queryKey: ["analytics"],
  queryFn: () => apiClient.analytics.getMe(),
  enabled: user?.role === "PROVIDER",
  retry: false,
});
```

### Rule 2 — Import hygiene after deletions
When a method is removed from a service, **simultaneously** remove every import of that method
in every file that referenced it (routers, tests, other services). Never leave stale imports
in files that called a now-deleted method — they cause TypeScript errors and, in Python,
`ImportError` at startup.

### Rule 3 — Verify field existence before use
Before referencing any field on a typed object (e.g., `booking.provider_display_name`),
**confirm the field exists** in the TypeScript type in `packages/types/src/index.ts` or the
Pydantic schema. Never assume a convenience field exists because it would be useful. If the
field is absent, either add it to the type contract or remove the reference.

### Rule 4 — No stub `onClick`/`onPress` handlers
Every `onClick`/`onPress` must be fully implemented. `onClick={() => {/* TODO: pagination */}}`
is not acceptable. If a feature is not yet ready, either disable the button
(`disabled={true}`) or remove it from the JSX. Never ship a dead interactive element.

### Rule 5 — Presigned URL content-type must match actual file
When calling the upload presign endpoint, pass the **actual file's content type** from
`file.type`. Never hardcode `"image/jpeg"` for a file input that accepts `image/*`.
A hardcoded type causes Spaces to return 403 `SignatureDoesNotMatch` for PNG, WebP,
and other formats.

```typescript
// WRONG
mutationFn: (fileName: string) =>
  apiClient.uploads.presign({ filename: fileName, content_type: "image/jpeg" });

// CORRECT
mutationFn: ({ fileName, contentType }: { fileName: string; contentType: string }) =>
  apiClient.uploads.presign({ filename: fileName, content_type: contentType });
```

### Rule 6 — All imports must be used
Every imported hook, component, or value must appear in the component body or return block.
An import that is never referenced must not exist. Before finalizing any file, scan every
`import` statement against actual usage.

### Rule 7 — Match all JSX opening/closing tags
Typos in closing tag names (e.g., `</tewxt>` instead of `</Text>`) crash the React Native
renderer immediately — the error message does not point at the typo, so they are hard to
debug. Triple-check every closing tag matches its opening tag exactly, including casing.

### Rule 8 — `ApiClient` namespaces are class properties, not methods
When adding a `reviews`, `billing`, `analytics`, or any other namespace to `ApiClient`,
declare it as a **class property with an object literal**, not as a method returning an
object. Match the existing pattern exactly:

```typescript
// CORRECT — class property
reviews = {
  createForBooking: (bookingId: string, body: { rating: number; body?: string }) =>
    this.request<Review>("POST", `/reviews/bookings/${bookingId}`, body),
};

// WRONG — method, `this` binding breaks
reviews() {
  return { createForBooking: ... };
}
```

### Rule 9 — Mobile uses relative imports only
`apps/mobile` has no `@/` path alias configured (unlike `apps/web`). Every import in a
mobile file must use a relative path.

```typescript
// WRONG (mobile)
import { useAuth } from "@/hooks/useAuth";

// CORRECT (mobile)
import { useAuth } from "../../hooks/useAuth";
```

### Rule 10 — SQLAlchemy 2.x count queries
Always use `select(func.count()).select_from(Model)` or
`select(func.count()).select_from(query.subquery())`. Never call `.with_only_columns(func.count())`
on a filtered query — that is a 1.x pattern that silently drops WHERE clauses in 2.x.

```tsx
import { useEffect, useState } from "react";
import { useSearchParams, useNavigate } from "react-router-dom";
import { loadStripe } from "@stripe/stripe-js";
import {
  Elements,
  PaymentElement,
  useStripe,
  useElements,
} from "@stripe/react-stripe-js";
import { apiClient } from "@/lib/apiClient";

const stripePromise = loadStripe(import.meta.env.VITE_STRIPE_PUBLISHABLE_KEY ?? "");

export default function BillingCheckoutPage() {
  const [searchParams] = useSearchParams();
  const navigate = useNavigate();
  const tier = searchParams.get("tier") ?? "";
  const [clientSecret, setClientSecret] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    if (!tier) {
      navigate("/billing");
      return;
    }
    apiClient.billing
      .subscribe(tier)
      .then((res) => setClientSecret(res.client_secret))
      .catch((err: unknown) =>
        setError(err instanceof Error ? err.message : "Failed to start checkout"),
      );
  }, [tier, navigate]);

  if (error) {
    return (
      <div style={{ maxWidth: 480, margin: "80px auto", padding: 24 }}>
        <h2>Checkout error</h2>
        <p style={{ color: "#ef4444" }}>{error}</p>
        <button onClick={() => navigate("/billing")} style={btnStyle}>
          Back to plans
        </button>
      </div>
    );
  }

  if (!clientSecret) {
    return <div style={{ padding: 32, textAlign: "center" }}>Setting up checkout…</div>;
  }

  return (
    <div style={{ maxWidth: 480, margin: "60px auto", padding: 24, fontFamily: "sans-serif" }}>
      <h1 style={{ fontSize: 24, marginBottom: 8 }}>Complete your subscription</h1>
      <p style={{ color: "#6b7280", marginBottom: 24, fontSize: 14 }}>
        You're subscribing to the <strong>{tier}</strong> plan.
      </p>
      <Elements stripe={stripePromise} options={{ clientSecret }}>
        <CheckoutForm tier={tier} />
      </Elements>
    </div>
  );
}

function CheckoutForm({ tier }: { tier: string }) {
  const stripe = useStripe();
  const elements = useElements();
  const navigate = useNavigate();
  const [submitting, setSubmitting] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    if (!stripe || !elements) return;

    setSubmitting(true);
    setError(null);

    const { error: stripeError } = await stripe.confirmPayment({
      elements,
      confirmParams: {
        return_url: `${window.location.origin}/billing?subscribed=${tier}`,
      },
    });

    // confirmPayment only returns here on error — success redirects to return_url.
    if (stripeError) {
      setError(stripeError.message ?? "Payment failed");
    }
    setSubmitting(false);
  }

  return (
    <form onSubmit={handleSubmit} style={{ display: "flex", flexDirection: "column", gap: 20 }}>
      <PaymentElement />
      {error && <p style={{ color: "#ef4444", fontSize: 14, margin: 0 }}>{error}</p>}
      <div style={{ display: "flex", gap: 12, justifyContent: "flex-end" }}>
        <button
          type="button"
          onClick={() => navigate("/billing")}
          style={{
            padding: "10px 20px",
            border: "1px solid #d1d5db",
            borderRadius: 8,
            background: "white",
            cursor: "pointer",
            fontSize: 14,
          }}
        >
          Cancel
        </button>
        <button
          type="submit"
          disabled={!stripe || submitting}
          style={btnStyle}
        >
          {submitting ? "Processing…" : "Subscribe"}
        </button>
      </div>
    </form>
  );
}

const btnStyle: React.CSSProperties = {
  background: "#4f46e5",
  color: "white",
  border: "none",
  borderRadius: 8,
  padding: "10px 20px",
  fontWeight: 600,
  fontSize: 14,
  cursor: "pointer",
};
```

### 3a. `dispatch_referral_rewards` Celery task

Add to `apps/api/app/workers/tasks.py`:

```python
@celery_app.task
def dispatch_referral_rewards() -> None:
    """
    Find CLAIMED referrals whose referred user has completed at least one booking,
    issue a Stripe coupon to the referrer, and mark the referral as REWARDED.

    Runs nightly. Idempotent — REWARDED referrals are skipped because they are
    filtered by status == CLAIMED.
    """
    from app.models.booking import Booking, BookingStatus
    from app.models.referral import Referral, ReferralStatus

    engine = create_engine(settings.database_sync_url)
    with SyncSession(engine) as session:
        # Find all CLAIMED referrals.
        claimed = session.scalars(
            select(Referral).where(Referral.status == ReferralStatus.CLAIMED)
        ).all()

        for referral in claimed:
            if not referral.referred_id:
                continue

            # Check if the referred user has at least one COMPLETED booking.
            has_completed = session.scalar(
                select(func.count())
                .select_from(Booking)
                .where(
                    Booking.customer_id == referral.referred_id,
                    Booking.status == BookingStatus.COMPLETED,
                )
            ) or 0

            if has_completed == 0:
                continue

            # Issue the reward — enqueue per-referral so failures are isolated.
            issue_referral_reward.delay(str(referral.id))

        session.commit()

    engine.dispose()


@celery_app.task(bind=True, max_retries=3, default_retry_delay=120)
def issue_referral_reward(self, referral_id: str) -> None:
    """
    Issue a one-month free coupon to the referrer via Stripe and mark the
    referral as REWARDED. Retries up to 3 times on failure.
    """
    try:
        _issue_referral_reward(referral_id)
    except Exception as exc:
        raise self.retry(exc=exc)
```

Add the implementation helper `_issue_referral_reward(referral_id: str) -> None`:

```python
def _issue_referral_reward(referral_id: str) -> None:
    """
    Helper (synchronous) — loads the referral, issues a Stripe coupon, marks REWARDED.

    Coupon: one free month applied as a 100% discount for one invoice cycle.
    Uses Stripe's Customer-level promotion code so it applies automatically
    on the next renewal invoice.
    """
    import stripe
    from app.models.referral import Referral, ReferralStatus
    from app.models.provider import ProviderProfile
    from datetime import datetime, timezone

    stripe.api_key = settings.stripe_secret_key

    engine = create_engine(settings.database_sync_url)
    with SyncSession(engine) as session:
        referral = session.get(Referral, referral_id)
        if not referral or referral.status != ReferralStatus.CLAIMED:
            # Already rewarded or not found — idempotent exit.
            return

        # Resolve the referrer's Stripe customer ID via their ProviderProfile.
        profile = session.scalar(
            select(ProviderProfile).where(ProviderProfile.user_id == referral.referrer_id)
        )

        if profile and profile.stripe_customer_id and settings.stripe_secret_key:
            # Create a one-time coupon (100% off for one invoice cycle).
            coupon = stripe.Coupon.create(
                percent_off=100,
                duration="once",
                name="Referral reward — 1 month free",
            )
            stripe.Customer.create_balance_transaction(
                profile.stripe_customer_id,
                # Alternatively, apply coupon to subscription:
                # stripe.Subscription.modify(sub.stripe_subscription_id, coupon=coupon.id)
                # Using balance credit is simpler and requires no active subscription lookup.
                amount=-3900,  # $39.00 credit (Pro tier price in cents — adjust as needed)
                currency="usd",
                description=f"Referral reward for code {referral.code}",
            )

        referral.status = ReferralStatus.REWARDED
        referral.rewarded_at = datetime.now(timezone.utc)
        session.commit()

    engine.dispose()
```

> **Note on reward amount:** The credit amount (`-3900` cents = $39.00) is hardcoded to the
> Pro tier price as a reasonable default. A future improvement would look up the referrer's
> actual subscription tier and credit the matching amount. For now hardcoding is acceptable
> and explicit; add a comment to that effect.

### 5a. `apps/web/src/hooks/useProviderSettings.ts`

```typescript
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { apiClient } from "@/lib/apiClient";
import type { ProviderProfile } from "@mysitter/types";

export function useMyProviderProfile() {
  return useQuery<ProviderProfile>({
    queryKey: ["providers", "me"],
    queryFn: () => apiClient.providers.getMyProfile(),
    retry: false,
  });
}

export function useUpdateProviderProfile() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (body: {
      bio?: string;
      services?: string[];
      hourly_rate?: number;
      service_radius_miles?: number;
    }) => apiClient.providers.updateMyProfile(body),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ["providers", "me"] });
      qc.invalidateQueries({ queryKey: ["auth", "me"] });
    },
  });
}
```

### 5b. `apps/web/src/pages/ProviderSettingsPage.tsx`

```tsx
import { useState, useEffect } from "react";
import { useAuth } from "@/hooks/useAuth";
import { useMyProviderProfile, useUpdateProviderProfile } from "@/hooks/useProviderSettings";
import { useNavigate } from "react-router-dom";
import type { ServiceType } from "@mysitter/types";

const ALL_SERVICES: ServiceType[] = [
  "PET_SITTING",
  "HOUSE_SITTING",
  "DOG_WALKING",
  "DROP_IN_VISIT",
  "DOGGY_DAY_CARE",
  "BOARDING",
];

const SERVICE_LABELS: Record<ServiceType, string> = {
  PET_SITTING: "Pet Sitting",
  HOUSE_SITTING: "House Sitting",
  DOG_WALKING: "Dog Walking",
  DROP_IN_VISIT: "Drop-In Visit",
  DOGGY_DAY_CARE: "Doggy Day Care",
  BOARDING: "Boarding",
};

export default function ProviderSettingsPage() {
  const { user } = useAuth();
  const navigate = useNavigate();
  const { data: profile, isLoading } = useMyProviderProfile();
  const update = useUpdateProviderProfile();

  const [bio, setBio] = useState("");
  const [services, setServices] = useState<ServiceType[]>([]);
  const [hourlyRate, setHourlyRate] = useState("");
  const [radiusMiles, setRadiusMiles] = useState("10");
  const [success, setSuccess] = useState(false);
  const [error, setError] = useState<string | null>(null);

  // Redirect non-providers.
  useEffect(() => {
    if (user && user.role !== "PROVIDER") {
      navigate("/dashboard");
    }
  }, [user, navigate]);

  // Populate form from loaded profile.
  useEffect(() => {
    if (!profile) return;
    setBio(profile.bio ?? "");
    setServices((profile.services ?? []) as ServiceType[]);
    setHourlyRate(profile.hourly_rate != null ? String(profile.hourly_rate) : "");
    setRadiusMiles(String(profile.service_radius_miles ?? 10));
  }, [profile]);

  function toggleService(type: ServiceType) {
    setServices((prev) =>
      prev.includes(type) ? prev.filter((s) => s !== type) : [...prev, type],
    );
  }

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    setError(null);
    setSuccess(false);
    try {
      await update.mutateAsync({
        bio: bio || undefined,
        services,
        hourly_rate: hourlyRate ? Number(hourlyRate) : undefined,
        service_radius_miles: Number(radiusMiles),
      });
      setSuccess(true);
    } catch (err) {
      setError(err instanceof Error ? err.message : "Update failed");
    }
  }

  if (isLoading) return <div style={{ padding: 32 }}>Loading your profile…</div>;

  return (
    <div style={{ maxWidth: 600, margin: "40px auto", padding: 24, fontFamily: "sans-serif" }}>
      <h1 style={{ fontSize: 24, marginBottom: 8 }}>Sitter Profile Settings</h1>
      <p style={{ color: "#6b7280", marginBottom: 28, fontSize: 14 }}>
        This information is shown to customers on your public profile. Complete it to
        appear in search results.
      </p>

      <form onSubmit={handleSubmit} style={{ display: "flex", flexDirection: "column", gap: 20 }}>
        {/* Bio */}
        <label style={{ fontSize: 14, fontWeight: 600 }}>
          About you
          <textarea
            value={bio}
            onChange={(e) => setBio(e.target.value)}
            rows={5}
            placeholder="Describe your experience with pets, your home setup, and your availability…"
            style={{
              display: "block",
              width: "100%",
              marginTop: 4,
              padding: 10,
              border: "1px solid #d1d5db",
              borderRadius: 8,
              fontSize: 15,
              resize: "vertical",
              fontFamily: "inherit",
              boxSizing: "border-box",
            }}
          />
        </label>

        {/* Services */}
        <fieldset style={{ border: "1px solid #d1d5db", borderRadius: 8, padding: "12px 16px" }}>
          <legend style={{ fontSize: 14, fontWeight: 600, padding: "0 4px" }}>
            Services offered
          </legend>
          <div
            style={{
              display: "grid",
              gridTemplateColumns: "repeat(auto-fill, minmax(180px, 1fr))",
              gap: 10,
              marginTop: 8,
            }}
          >
            {ALL_SERVICES.map((type) => (
              <label
                key={type}
                style={{ display: "flex", alignItems: "center", gap: 8, cursor: "pointer" }}
              >
                <input
                  type="checkbox"
                  checked={services.includes(type)}
                  onChange={() => toggleService(type)}
                  style={{ width: 16, height: 16 }}
                />
                <span style={{ fontSize: 14 }}>{SERVICE_LABELS[type]}</span>
              </label>
            ))}
          </div>
        </fieldset>

        {/* Hourly rate */}
        <label style={{ fontSize: 14, fontWeight: 600 }}>
          Hourly rate (USD)
          <div style={{ display: "flex", alignItems: "center", gap: 6, marginTop: 4 }}>
            <span style={{ fontSize: 16 }}>$</span>
            <input
              type="number"
              min={1}
              max={500}
              value={hourlyRate}
              onChange={(e) => setHourlyRate(e.target.value)}
              placeholder="e.g. 25"
              style={{
                width: 120,
                padding: 10,
                border: "1px solid #d1d5db",
                borderRadius: 8,
                fontSize: 15,
                boxSizing: "border-box",
              }}
            />
            <span style={{ fontSize: 13, color: "#6b7280" }}>/hr</span>
          </div>
        </label>

        {/* Service radius */}
        <label style={{ fontSize: 14, fontWeight: 600 }}>
          Service radius: {radiusMiles} miles
          <input
            type="range"
            min={1}
            max={50}
            value={radiusMiles}
            onChange={(e) => setRadiusMiles(e.target.value)}
            style={{ display: "block", width: "100%", marginTop: 4 }}
          />

            <span>1 mi</span>
            <span>50 mi</span>
          </div>
        </label>

        {success && (
          <p style={{ color: "#059669", fontSize: 14, margin: 0, fontWeight: 600 }}>
            ✓ Profile updated
          </p>
        )}
        {error && (
          <p style={{ color: "#ef4444", fontSize: 14, margin: 0 }}>{error}</p>

            borderRadius: 10,
```

## Review Focus Checklist (for Claude post-Gemini review)

Apply all rules from the **Gemini Code Generation Rules** section above, plus verify:

1. **`BillingCheckoutPage` env var** — `VITE_STRIPE_PUBLISHABLE_KEY` is read from `import.meta.env`, not hardcoded. Verify it's in `.env.example`.
2. **Stripe `confirmPayment` return** — `confirmPayment` only returns on error; success is a redirect. Verify the component doesn't try to handle a success return value.
3. **Push token `useEffect` dependency** — The token registration effect must depend on `user?.id`, not `user`, to avoid infinite re-runs (object identity changes on every render in some auth implementations).
4. **`dispatch_referral_rewards` idempotency** — The reward task must re-check `referral.status == CLAIMED` inside `_issue_referral_reward` before proceeding, in case two task instances run concurrently.
5. **NavBar `useAuth` on unauth pages** — `NavBar` reads `user` from `useAuth()`. On login/register pages the user is `null` and the component returns `null` immediately — verify `useAuth()` is safe to call when unauthenticated (it should be, since `useAuth` just reads query cache).
6. **ProviderSettingsPage `useEffect` for profile data** — The `useEffect` that populates form state from `profile` must have `profile` in its dependency array. Missing it means the form never fills in on first load.
7. **SQLite test database vs PostGIS** — `conftest.py` uses SQLite for speed but `ProviderProfile.location` is a GeoAlchemy2 column. Tests that create provider profiles will fail on SQLite. Either skip those tests (mark with `pytest.mark.skip`) or add a `@pytest.mark.geo` marker with a Postgres-required fixture.
8. **Mobile `Linking` import** — `Linking` must be imported from `react-native` (it's a named export, not a default). Verify the import line: `import { ..., Linking } from "react-native"`.
9. **`expo-notifications` in `package.json`** — Before using `expo-notifications` in `_layout.tsx`, verify it's in `apps/mobile/package.json`. If Gemini uses it without checking, add it.
10. **Stripe package in web** — Before using `@stripe/stripe-js` and `@stripe/react-stripe-js`, verify both are in `apps/web/package.json` `dependencies`. If missing, add them.
