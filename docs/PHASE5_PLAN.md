### `deploy/nginx.conf` — TLS + WebSocket

Replace the entire file content. The new config has three server blocks:

1. An HTTP server on port 80 that performs a permanent redirect to HTTPS for all non-ACME traffic (the `/.well-known/acme-challenge/` location is served from a local directory so Certbot can complete HTTP-01 challenges without downtime).
2. An HTTPS server on port 443 with a WebSocket-aware `location /ws/` block and the main API proxy block.
3. Comments explaining exactly where to drop Let's Encrypt paths.

```nginx
# ── Rate limiting ─────────────────────────────────────────────────────────────
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=30r/s;

upstream api_backend {
    server api1:8000;
    server api2:8000;
    keepalive 32;
}

# ── HTTP → HTTPS redirect (port 80) ──────────────────────────────────────────
# ACME challenge directory is served here so Certbot can renew certs without
# taking down the redirect.
server {
    listen 80;
    server_name _;

    # Let's Encrypt HTTP-01 challenge — served from a volume or bind-mount:
    #   volumes: ["certbot_webroot:/var/www/certbot"]
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }

    location / {
        return 301 https://$host$request_uri;
    }
}

# ── HTTPS (port 443) ──────────────────────────────────────────────────────────
server {
    listen 443 ssl;
    server_name _;

    # ── TLS certificates ────────────────────────────────────────────────────
    # Option A (self-signed for staging — generates a cert if none exists):
    #   openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    #     -keyout /etc/ssl/private/nginx-selfsigned.key \
    #     -out /etc/ssl/certs/nginx-selfsigned.crt \
    #     -subj "/CN=mysitter.local"
    ssl_certificate     /etc/ssl/certs/nginx-selfsigned.crt;
    ssl_certificate_key /etc/ssl/private/nginx-selfsigned.key;

    # Option B (Let's Encrypt production — replace paths after first certbot run):
    #   ssl_certificate     /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    #   ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;
    #   include /etc/letsencrypt/options-ssl-nginx.conf;
    #   ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache   shared:SSL:10m;
    ssl_session_timeout 10m;

    # ── Health check (exempt from rate limiting) ─────────────────────────────
    location /health {
        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
    }

    # ── WebSocket connections ─────────────────────────────────────────────────
    # Must appear before the catch-all location / so it takes priority.
    # FastAPI's websocket router is mounted at /ws/ in main.py.
    location /ws/ {
        proxy_pass http://api_backend;
        proxy_http_version 1.1;

        # Required WebSocket upgrade headers — these MUST be set.
        # Without them nginx sends "Connection: close" and the upgrade handshake fails.
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket connections are long-lived — increase the read timeout.
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }

    # ── API (all other paths) ─────────────────────────────────────────────────
    location / {
        limit_req zone=api_limit burst=60 nodelay;

        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }
}
```

### 2a. `MessagingService.mark_conversation_read`

Add this method to `MessagingService` in `messaging_service.py`:

```python
async def mark_conversation_read(
    self, user: User, conversation_id: uuid.UUID
) -> int:
    """
    Set read_at = now() on all messages in this conversation
    where the current user is NOT the sender and read_at IS NULL.
    Returns the count of rows updated.
    """
    from datetime import datetime, timezone
    from sqlalchemy import update as sa_update

    conv = await self.get_conversation_for_user(user, conversation_id)
    if not conv:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND)

    now = datetime.now(timezone.utc)
    result = await self._db.execute(
        sa_update(Message)
        .where(
            Message.conversation_id == conversation_id,
            Message.sender_id != user.id,
            Message.read_at.is_(None),
        )
        .values(read_at=now)
    )
    await self._db.commit()
    return result.rowcount
```

### 3a. Availability block validation in `_check_conflicts`

Add a second private method `_check_availability_coverage` to `BookingService` and call it from `confirm` alongside the existing `_check_conflicts` call.

```python
async def _check_availability_coverage(
    self,
    provider_id: uuid.UUID,
    start_at: datetime,
    end_at: datetime,
) -> None:
    """
    Raise 422 if the requested window is not covered by any of the provider's
    Availability blocks.

    Coverage rules:
    - A non-recurring block covers the window if its start_at <= booking.start_at
      AND its end_at >= booking.end_at.
    - A recurring block is expanded via dateutil.rrule. An occurrence covers the
      window if occurrence_start <= booking.start_at AND
      (occurrence_start + block_duration) >= booking.end_at.
    """
    from dateutil.rrule import rrulestr
    from app.models.provider import Availability

    blocks = list(
        (
            await self._db.execute(
                select(Availability).where(Availability.provider_id == provider_id)
            )
        )
        .scalars()
        .all()
    )

    booking_duration = end_at - start_at
    search_from = start_at - booking_duration  # expand a bit for rrule search
    search_to = end_at

    for block in blocks:
        block_duration = block.end_at - block.start_at
        if block.rrule_string:
            rule = rrulestr(block.rrule_string, dtstart=block.start_at)
            for occ_start in rule.between(search_from, search_to, inc=True):
                occ_end = occ_start + block_duration
                if occ_start <= start_at and occ_end >= end_at:
                    return  # covered
        else:
            if block.start_at <= start_at and block.end_at >= end_at:
                return  # covered

    raise HTTPException(
        status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
        detail="The requested time window does not fall within the provider's availability",
    )
```

Call this in `BookingService.confirm` immediately before `_check_conflicts`:

await self._check_conflicts(booking.provider_id, booking.start_at, booking.end_at, booking.id)

@celery_app.task
def dispatch_booking_reminders() -> None:
    """
    Find all CONFIRMED bookings whose start_at is between 23h and 25h from now
    and enqueue a send_booking_reminder task for each.
    The 2-hour window (±1h around the 24h mark) prevents double-sends if the
    hourly beat fires slightly early or late.
    """
    from datetime import datetime, timedelta, timezone

    now = datetime.now(timezone.utc)
    window_start = now + timedelta(hours=23)
    window_end = now + timedelta(hours=25)

    engine = create_engine(settings.database_sync_url)
    with SyncSession(engine) as session:
        upcoming = session.scalars(
            select(Booking).where(
                Booking.status == BookingStatus.CONFIRMED,
                Booking.start_at >= window_start,
                Booking.start_at <= window_end,
            )
        ).all()
        for booking in upcoming:
            send_booking_reminder.delay(str(booking.id))
    engine.dispose()
```

@celery_app.task
def deactivate_expired_grace_periods() -> None:
    """
    Find ProviderProfiles in 'grace_period' subscription_status whose
    Subscription.current_period_end has passed, and deactivate their listings.

    This is the complement of _on_payment_failed in StripeService: that handler
    sets status to 'grace_period'; this task enforces the expiry.
    """
    from datetime import datetime, timezone
    from app.models.provider import ProviderProfile, Subscription

    now = datetime.now(timezone.utc)
    engine = create_engine(settings.database_sync_url)

    with SyncSession(engine) as session:
        expired = session.scalars(
            select(ProviderProfile)
            .join(Subscription, Subscription.provider_id == ProviderProfile.id)
            .where(
                ProviderProfile.subscription_status == "grace_period",
                Subscription.current_period_end < now,
            )
        ).all()

        for profile in expired:
            profile.is_active = False
            profile.subscription_status = "expired"

        session.commit()

    engine.dispose()
```

const API_URL = import.meta.env.VITE_API_URL as string;

export const authProvider: AuthProvider = {
  login: async ({ username, password }: { username: string; password: string }) => {

      throw new Error(err.detail ?? "Login failed");

  },

    localStorage.removeItem("access_token");
    // Call the API logout to clear the refresh cookie.
    await fetch(`${API_URL}/auth/logout`, {
      method: "POST",
      credentials: "include",
    }).catch(() => {}); // ignore errors on logout
  },

  checkAuth: () =>
    localStorage.getItem("access_token")
      ? Promise.resolve()
      : Promise.reject(),

  checkError: (error: { status?: number }) => {
    if (error.status === 401 || error.status === 403) {
      localStorage.removeItem("access_token");
      return Promise.reject();
    }
    return Promise.resolve();
  },

    // Decode the JWT payload (no signature verification needed client-side).
    const token = localStorage.getItem("access_token");

      const payload = JSON.parse(atob(token.split(".")[1]));
      return payload.role ?? null;

      return null;

    const token = localStorage.getItem("access_token");

from pydantic import BaseModel as _BaseModel

class AdminStats(_BaseModel):
    total_users: int
    active_providers: int
    total_bookings: int
    confirmed_bookings: int
    completed_bookings: int
    total_subscriptions: int
    active_subscriptions: int
    # Revenue: sum of hourly_rate * session hours for completed bookings
    # (approximation — real revenue tracking requires Stripe invoice amounts)
    estimated_revenue_usd: float


@router.get("/stats", response_model=AdminStats)
async def get_stats(
    _: User = Depends(_admin_only),
    db: AsyncSession = Depends(get_db),
) -> AdminStats:
    from sqlalchemy import case, cast, Float

    total_users = await db.scalar(select(func.count()).select_from(User)) or 0
    active_providers = await db.scalar(
        select(func.count()).select_from(ProviderProfile).where(ProviderProfile.is_active.is_(True))
    ) or 0
    total_bookings = await db.scalar(select(func.count()).select_from(Booking)) or 0
    confirmed_bookings = await db.scalar(
        select(func.count()).select_from(Booking).where(Booking.status == BookingStatus.CONFIRMED)
    ) or 0
    completed_bookings = await db.scalar(
        select(func.count()).select_from(Booking).where(Booking.status == BookingStatus.COMPLETED)
    ) or 0
    total_subscriptions = await db.scalar(select(func.count()).select_from(Subscription)) or 0
    active_subscriptions = await db.scalar(
        select(func.count()).select_from(Subscription).where(Subscription.status == "active")
    ) or 0

    # Estimated revenue: sum over completed bookings of
    # (hourly_rate * (end_at - start_at) / 3600) joined to provider_profiles
    revenue_row = await db.execute(
        select(
            func.coalesce(
                func.sum(
                    cast(ProviderProfile.hourly_rate, Float)
                    * func.extract("epoch", Booking.end_at - Booking.start_at)
                    / 3600
                ),
                0.0,
            )
        )
        .select_from(Booking)
        .join(ProviderProfile, ProviderProfile.id == Booking.provider_id)
        .where(
            Booking.status == BookingStatus.COMPLETED,
            ProviderProfile.hourly_rate.isnot(None),
        )
    )
    estimated_revenue = float(revenue_row.scalar_one())

    return AdminStats(
        total_users=total_users,
        active_providers=active_providers,
        total_bookings=total_bookings,
        confirmed_bookings=confirmed_bookings,
        completed_bookings=completed_bookings,
        total_subscriptions=total_subscriptions,
        active_subscriptions=active_subscriptions,
        estimated_revenue_usd=round(estimated_revenue, 2),
    )

@router.post("/notifications/send", response_model=_ManualNotificationResponse)
async def send_manual_notification(
    body: _ManualNotificationRequest,
    _: User = Depends(_admin_only),
    db: AsyncSession = Depends(get_db),
) -> _ManualNotificationResponse:
    """
    Queue a manual notification to specific users (or all users if user_ids is empty).
    Delegates to the existing send_admin_broadcast Celery task.
    """
    if body.user_ids:
        target_ids = [str(uid) for uid in body.user_ids]
    else:
        # Broadcast: load all active user IDs
        rows = await db.execute(
            select(User.id).where(User.is_active.is_(True))
        )
        target_ids = [str(r) for r in rows.scalars()]

    from app.workers.tasks import send_admin_notification
    for user_id in target_ids:
        send_admin_notification.delay(
            user_id=user_id,
            subject=body.subject,
            message=body.message,
            channels=body.channels,
        )

    return _ManualNotificationResponse(queued=len(target_ids))

### 6d. `apps/api/app/services/referral_service.py`

```python
"""
ReferralService: generate codes, claim codes on registration, issue rewards.

Reward logic (Phase 5 implementation):
  - When a referred user completes their first booking, the referrer receives
    a Stripe coupon for one free month (applied via Stripe Customer Billing Portal).
  - The reward is idempotent: a referral row can only transition PENDING→CLAIMED→REWARDED.

Reward issuance is out-of-band in this phase — a Celery task checks for
CLAIMED referrals nightly and issues rewards where the referred user has
at least one COMPLETED booking.
"""
import secrets
import uuid
from datetime import datetime, timezone

from fastapi import HTTPException, status
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.referral import Referral, ReferralStatus
from app.models.user import User
from app.schemas.referral import ReferralListResponse, ReferralResponse


def _generate_code() -> str:
    """8 alphanumeric characters, uppercase. Collision probability negligible."""
    return secrets.token_urlsafe(6)[:8].upper()


class ReferralService:
    def __init__(self, db: AsyncSession) -> None:
        self._db = db

    async def generate(self, user: User) -> ReferralResponse:
        """
        Create a new referral code for the current user.
        One active (PENDING) code per user is allowed. If one exists, return it.
        """
        existing = await self._db.scalar(
            select(Referral).where(
                Referral.referrer_id == user.id,
                Referral.status == ReferralStatus.PENDING,
            )
        )
        if existing:
            return ReferralResponse.model_validate(existing)

        # Collision retry loop (extremely unlikely — just good practice).
        for _ in range(5):
            code = _generate_code()
            clash = await self._db.scalar(select(Referral).where(Referral.code == code))
            if not clash:
                break
        else:
            raise HTTPException(
                status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
                detail="Could not generate unique referral code",
            )

        referral = Referral(referrer_id=user.id, code=code)
        self._db.add(referral)
        await self._db.commit()
        await self._db.refresh(referral)
        return ReferralResponse.model_validate(referral)

    async def claim(self, code: str, new_user: User) -> ReferralResponse:
        """
        Called during registration when a user supplies a referral code.
        Transitions the referral from PENDING → CLAIMED.
        Raises 404 if code doesn't exist; 409 if already claimed.
        """
        referral = await self._db.scalar(
            select(Referral).where(Referral.code == code.upper())
        )
        if not referral:
            raise HTTPException(
                status_code=status.HTTP_404_NOT_FOUND,
                detail="Referral code not found",
            )
        if referral.status != ReferralStatus.PENDING:
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Referral code has already been used",
            )
        if referral.referrer_id == new_user.id:
            raise HTTPException(
                status_code=status.HTTP_400_BAD_REQUEST,
                detail="You cannot use your own referral code",
            )

        referral.referred_id = new_user.id
        referral.status = ReferralStatus.CLAIMED
        referral.claimed_at = datetime.now(timezone.utc)
        await self._db.commit()
        await self._db.refresh(referral)
        return ReferralResponse.model_validate(referral)

    async def list_for_user(self, user: User) -> ReferralListResponse:
        """Return all referrals created by this user."""
        rows = list(
            (
                await self._db.execute(
                    select(Referral)
                    .where(Referral.referrer_id == user.id)
                    .order_by(Referral.created_at.desc())
                )
            )
            .scalars()
            .all()
        )
        return ReferralListResponse(
            referrals=[ReferralResponse.model_validate(r) for r in rows],
            total_claimed=sum(1 for r in rows if r.status != ReferralStatus.PENDING),
            total_rewarded=sum(1 for r in rows if r.status == ReferralStatus.REWARDED),
        )
```

### 7b. Avatar upload validation via presigned URL

The gap is in `PATCH /users/me` which accepts any `avatar_url` string. The fix enforces that `avatar_url` values must come from the platform's own storage domain.

In `apps/api/app/schemas/user.py`, add a validator to `UserUpdateRequest`:

```python
from pydantic import BaseModel, field_validator
from app.core.config import settings

class UserUpdateRequest(BaseModel):
    display_name: str | None = None
    phone: str | None = None
    avatar_url: str | None = None

    @field_validator("avatar_url")
    @classmethod
    def validate_avatar_url(cls, v: str | None) -> str | None:
        if v is None:
            return v
        # Accept only URLs that originate from the configured Spaces bucket.
        # settings.spaces_endpoint is e.g. "https://sfo3.digitaloceanspaces.com"
        # The public URL pattern is "https://{bucket}.{region}.digitaloceanspaces.com/..."
        allowed_prefix = settings.spaces_endpoint.replace(
            "://", f"://{settings.spaces_bucket}."
        )
        if not v.startswith(allowed_prefix):
            from pydantic import ValidationError
            raise ValueError(
                f"avatar_url must be a URL from the platform storage domain. "
                f"Use POST /uploads/presign to obtain a valid upload URL."
            )
        return v
```

This validator is equivalent to checking that the URL was produced by `SpacesStorageRepository.generate_presigned_put` — any URL that doesn't start with `{bucket}.{region}.digitaloceanspaces.com` is rejected.

**Note:** In local development `settings.spaces_endpoint` may be empty or a mock URL. Guard the validator with `if settings.spaces_endpoint and settings.spaces_bucket` before running the check, returning `v` unchanged if either is not configured (test/dev environments).
